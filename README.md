# ☕ Java - Lógica de Programação

Repositório dedicado aos meus estudos e exercícios de lógica de programação utilizando **Java**.

Aqui compartilho exercícios desenvolvidos durante minha jornada de aprendizado, buscando aprimorar meu raciocínio lógico e minha capacidade de resolver problemas.

---

## 📚 Conteúdos estudados

- Variáveis e tipos de dados
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if/else`)
- Estruturas de repetição (`for`, `while` e `do-while`)
- Vetores
- Matrizes
- Entrada e saída de dados

---

## 📂 Organização

Os exercícios estão organizados em arquivos individuais, cada um contendo comentários com seu respectivo objetivo e descrição.

---

## 🎯 Objetivo

Praticar lógica de programação, desenvolver meu raciocínio lógico e acompanhar minha evolução no desenvolvimento com **Java**.
